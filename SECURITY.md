# Security policy

## Reporting a vulnerability

Please report security issues privately, never in a public issue, pull request
or discussion.

Use GitHub's private vulnerability reporting: open this repository's
**Security** tab and choose **Report a vulnerability**. Only the maintainers
can see the report.

Say what you found, where (file, route or page), and how to reproduce it.
Don't access, change or delete data that isn't yours, and stop once you have
shown the issue.

## Scope

- The code in this repository.
- The LogisX app deployed from it (app.logisx.com).

Third-party services the app uses (Google, GitHub, n8n, ELD providers and
others) are out of scope; report issues in those to their owners.

## How reports are handled

Reports are handled privately. Once a fix is deployed, it is described
publicly by what the app now does, not by how the issue could be used.
